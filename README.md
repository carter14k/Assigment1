Frames of Life

Author

Abdirahman Carter

Description

Frames of Life is a photography website created to celebrate memorable moments through images. It features favorite nature and motorsport photographs, an introduction to the project, information about the creator, and a contact form.

The project explores the use of HTML and CSS to create a visually appealing website with a dark theme, image gallery, navigation links, and responsive image styling.

Technologies Used

- HTML5
- CSS3
- Git and GitHub

Setup Instructions

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. To modify the website, edit "index.html" or "styles.css".

The original design mockup is included in the repository as "Design".
